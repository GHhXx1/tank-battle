# 坦克大战 · Tank Battle

一个纯 HTML5 Canvas 实现的经典《坦克大战》(Battle City) 复刻版。**单文件、零依赖**，直接用浏览器打开即可游玩。

## 玩法

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 / WASD |
| 射击 | 空格（或 J / X） |
| 暂停 | P |
| 静音 | M |

保护你的基地 🦅，消灭所有敌方坦克。

- 砖墙可被子弹击毁
- 钢墙需要满级火力（★★）才能破坏
- 草丛会隐藏坦克
- 水域无法通行（但子弹可以飞过）

## 特性

- 关卡递增，敌人数量与难度随关卡提升
- 4 种道具：★ 火力升级、💣 全屏炸弹、♥ 生命 +1、🛡 护盾
- 粒子爆炸特效、简单音效、响应式界面

## 运行

直接用浏览器打开 `index.html`，或启动本地服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
